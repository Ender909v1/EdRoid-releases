# EdRoid releases

Downloads for **EdRoid**, an Android app that runs PC game folders: RPG Maker MV/MZ and HTML5 games in a built-in web player, Windows `.exe` games in a built-in Windows engine.

Get the newest APK from [Releases](../../releases/latest) and open it on the phone to install or update. Games, saves and settings stay when you update. EdRoid checks `version.json` here when it starts and says when a newer version is out.

Requirements: Android 8 or newer, 64-bit (arm64).

## Third-party software

The Windows engine is based on [Winlator](https://github.com/brunodev85/winlator-app) (LGPL-2.1) and includes Wine (LGPL-2.1), Box64 (MIT), DXVK (zlib), VKD3D-Proton (LGPL-2.1) and Mesa Turnip (MIT). The source of EdRoid's modified engine is available on request through this repository's issues.
